# Quy định kỹ thuật: Database — PostgreSQL

> Dùng làm tài liệu tham chiếu cho skill backend (`develop-backend`/`fix-backend`, xem [`TECH-BACKEND.md`](./TECH-BACKEND.md)) mỗi khi cần tạo/sửa bảng, viết migration. Đi kèm [`TECH-ORM.md`](./TECH-ORM.md) — file đó nói về phía Hibernate/JPA map vào entity, file này nói về schema/migration thật trên PostgreSQL.

## 1. Version

- PostgreSQL bản **15 hoặc 16** — bất kỳ bản còn được hỗ trợ chính thức tại thời điểm cài đặt, tránh bản đã EOL.

## 2. Naming convention

- Tên bảng: `snake_case`, **số nhiều** (`transaction_histories`, `expense_jars`, `family_members`) — khớp mặc định của Hibernate `SpringPhysicalNamingStrategy` khi entity đặt tên số ít theo chuẩn Java.
- Tên cột: `snake_case`, khớp field entity qua naming strategy mặc định của Hibernate (không cần `@Column(name=...)` thủ công trừ khi tên khác biệt bất thường).
- Khóa chính: `id` (kiểu `BIGINT`, `GENERATED BY DEFAULT AS IDENTITY` — tương ứng `GenerationType.IDENTITY` phía JPA).
- Khóa ngoại: `<tên_bảng_số_ít>_id` (ví dụ `expense_jar_id` trong bảng `transaction_histories`).

## 3. Kiểu dữ liệu tiền

- Mọi cột tiền (`base_expense`, `expense`, `warning_threshold`, `emergency_threshold`, `approve_threshold`...) dùng **`DECIMAL(15,3)`** — đã chốt ở `../BUSINESS-REQUIREMENTS.md` mục 7.1, không dùng `FLOAT`/`DOUBLE PRECISION`.

## 4. Migration

- Dùng **Flyway** (tích hợp sẵn tốt với Spring Boot qua `spring-boot-starter-flyway` hoặc dependency `flyway-core`) — script đặt ở `src/main/resources/db/migration/`, đặt tên `V1__init_schema.sql`, `V2__add_xxx.sql`... tăng dần, **không sửa lại script đã chạy** (tạo script mới nếu cần đổi).
- **Không dùng Hibernate `ddl-auto=update`/`create` ở bất kỳ môi trường nào có dữ liệu thật** — chỉ dùng `validate` (Hibernate kiểm tra entity khớp schema, không tự đổi schema) song song với Flyway quản lý schema thật. Xem thêm `TECH-ORM.md`.

## 5. Kết nối & bảo mật

- Thông tin kết nối (`SPRING_DATASOURCE_URL`, `_USERNAME`, `_PASSWORD`) truyền qua biến môi trường — không hardcode trong `application.yml`/code (khớp `TECH-BACKEND.md` mục 2 và `TECH-CONTAINER.md`).
- Local dev: chạy PostgreSQL qua Docker Compose (xem `TECH-CONTAINER.md`) thay vì cài trực tiếp lên máy, để môi trường dev giống prod.
